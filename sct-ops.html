ストレスチェック実施者養成研修　運用マニュアル

事務の方向けです。受講者への案内と、運営画面での日々の操作をまとめています。

1. 入口

  • 受講者：https://rsaito-png.github.io/portal/sct.html（このマニュアルと同じ場所の sct.html）。アカウント作成、資格、免除の証明、予約、カード支払い、修了証はこちらです。
  • 運営：職員ポータルにログインします。トップの「ストレスチェック実施者養成（運営）」、または「総務」→ 人事労務の「実施者養成研修（運営）」を開きます。アドレスの末尾は #sct です。使えるのは事務と、運営権限（sct_admin）の人です。
  • このマニュアル：運営画面の上部にある「運用マニュアル」から開けます。アドレスは sct-ops.html です。

法定研修（ポータルの「法定研修」）とは別です。録画の配信だけで、好きな時間に見るオンデマンドはありません。

2. 料金（税込）

  • 3科目：12,800円。科目1・2・3を受けます。
  • 科目1免除（衛生管理者）：10,800円。科目2・3だけ受けます。免除の証明を見て、承認してからこの金額にします。
  • 全免除（労働衛生コンサルタント）：0円。受講は不要です。修了証は出しません。

金額は免除の区分から決まります。画面に金額を手入力しません。

  • 科目1「労働者の健康管理」2時間（120分）
  • 科目2「事業場におけるメンタルヘルス対策」1時間30分（90分）
  • 科目3「職場における個々の労働者及び労働者の集団への支援の方法」1時間30分（90分）

確認テストは記録できますが、点数は修了の条件にしません。修了は「対象科目の視聴時間」と「本人確認済み」です。

3. 開催を作る

  1. 運営画面の「開催」を開きます。
  2. 科目を選びます。講師は、何も変えていなければ 西岡愛梨 です。別の人は「講師」で追加してから選びます。実務年数は画面では判定しません。照合したら、講師のメモに残します。
  3. 開始と終了を日本時間で入れます。科目1は2時間、科目2と科目3は1時間30分にします。開催がこれより短いと、視聴時間が足りず修了できません。
  4. 定員は最初 20 です。必要なときだけ変えます。
  5. 状態を「募集中」にします。下書きのままでは受講者の一覧に出ません。
  6. Google Meet の URL を入れます。https:// から始まるアドレスだけ保存できます。受講者には、予約した人だけリンクが出ます。
  7. 「Meet space 名」は空で大丈夫です。自動の入退室連携を使うとき以外は入れません。
  8. 「保存」を押します。直すときは一覧の「直す」です。

当日は、運営が Meet で画面共有し、録画を流します。受講者はカメラをオンにします。

4. 免除の証明を確認する

受講者が免除を選んで証明（PDFか画像）を保存すると、確認待ちになります。待ちのあいだは支払いへ進めません。画面には「免除証明の確認待ちです」と出ます。承認する前に、科目1免除の 10,800円では案内しません。

  1. 「受講者・出席」で、その人の「免除の証明」を開いて中身を見ます。
  2. 衛生管理者で科目1を免除してよいときは「免除を認める」。料金は 10,800円（科目2・3）になります。
  3. 証明が違う、足りないときは「免除を却下」。料金は 3科目の 12,800円に戻ります。
  4. 労働衛生コンサルタントで全免除してよいときは「免除を認める」。料金は 0円です。修了証は出しません。

一覧の免除欄の読み方です。

  • none … 免除なし（12,800円）
  • subject1 / pending … 科目1免除の確認待ち（まだ支払えない）
  • subject1 / approved … 科目1免除を承認（10,800円）
  • subject1 / rejected … 却下（12,800円）
  • all / pending … 全免除の確認待ち
  • all / approved … 全免除（0円。修了証なし）

5. 入金を確認する

カードは受講者が「支払いへ進む」を押すと、Square の画面に移ります。カード番号はポータルに入力しません。

  • Square のカードは、支払いが完了した通知（webhook）で自動的に「入金済」になります。事務がボタンを押す必要はありません。
  • 受講者が戻ったアドレスのうしろが ?paid=1 でも、それだけでは入金にしません。受講者画面は「反映まで少しかかる場合があります」と出すだけです。
  • 振込は自動では付きません。「入金・返金」の「振込を記録」で、その人を選んでメモ（振込人名など）を入れ、「未入金として記録」します。通帳で入金を確認したら、その行の「入金確認」を押します。
  • Square の未完了（未入金のカード）が残っているときは、振込を記録する前に「無効」にします。
  • 全免除を承認済みの人は、金額 0円で「課金なし」になります。

方法の表示は、Square（今回のカード）、振込、なし、旧カード（以前のカード決済の記録）です。

6. 返金の目安

まずは振替を案内します。返金するときは、日数を開催日の日本時間の日付で数えます（時刻では見ません）。

  • 7日前まで：全額。Square の決済手数料の実費は引いてよいです。
  • 6日前から前日：半額。
  • 当日以降と無断欠席：返金なし。
  • 主催の都合：全額。

お金の移動は Square のダッシュボードで行います。ポータルは結果の状態を残すだけです。「入金・返金」で入金済の行の「返金を記録」を押し、区分・返金額・手数料の実費・理由を入れて「記録する」。

画面の提案額は、その人のいちばん早い予約の開催日と、今日の日付から出します。手数料は引いていないので、7日前までの全額で手数料を引くときは返金額を手で直します。主催都合の全額も、区分を自分で「全額（主催都合、または7日前まで）」にします。行は消しません。

7. 出席・本人確認・カメラ

  1. 「受講者・出席」で本人確認書類を開き、よければ「本人確認済」。違うときは「本人差戻し」。本人確認が済んでいないと修了できません。
  2. 入室と退室の時刻は、予約の「入退室」に日本時間で入れて「記録する」。Meet が自動で出席にはしません。
  3. 来ていれば「出席」、連絡なく来なければ「無断欠席」。
  4. カメラを切っていた時間が2分を超えた回は、運営が見て「カメラOFFで出席外し」を押します。確認が出ます。自動では外れません。外した回の視聴時間は 0 になります。

8. Meet の受信を出席に写す

「Meet受信」に入退室の受信が並ぶことがあります。自動では出席になりません。

  • 「出席に転記」は、受信の表示名が予約の氏名と1件だけ一致するときだけ、入退室の欄へ時刻を入れます。
  • 「表示名が予約1件と一致しません」と出たとき、まだ受信がないときは、「受講者・出席」の「入退室」へ手入力します。
  • いまの運用は手入力で足りています。受信が空でも修了まで進めます。

9. 修了と修了証

  1. 「受講者・出席」で視聴を確認します。対象の科目が、それぞれ 120分・90分・90分に足りていて、本人確認済みなら「修了可」です。
  2. 「修了処理」を押します。別の窓に修了証が出るので、ブラウザの印刷で紙かPDFにします。窓が出ないときは、ポップアップを許可してもう一度押します。
  3. 受講者も、条件を満たすと自分の画面の「修了証を表示」から同じ書面を出せます。
  4. 氏名の間違いは、修了処理の前に直します。出した控えは消せません。
  5. 全免除の人は修了処理できません。修了証は出しません。

帳簿、視聴の記録、本人確認、修了証の控え、決済、Meet の受信は削除できません。自動で消えることもありません。間違いや返金は、行を消さず状態を変えて残します。「帳簿」は見るだけです。

10. 年次の CSV

  1. 「年次CSV」を開きます。
  2. 年を入れて「表示」。
  3. 「CSV」でダウンロードします。ファイル名は sct-annual-その年.csv です。

開催年は、開始日時の日本時間の年です。中止した回は回数に入りません。修了者数は、その開催を1分以上見て、その科目が載った修了証がある人数です。

11. 困ったとき

  • 入金が反映されない：少し待って「入金・返金」を開き直します。まだ未入金なら、Square ダッシュボードの Payments（支払い）にその支払いがあるかを見ます。戻ったアドレスの ?paid=1 だけでは入金にしません。カードが拒否されても、行は失敗になりません。同じ支払いリンクでやり直せます。取りやめるときは「無効」です。
  • ログインできない：受講者は sct.html、職員の運営はポータルです。パスワードは、それぞれの「パスワードを忘れた」からやり直せます。運営画面に「事務または sct_admin だけが使えます」と出たら、権限を付けたあとに入り直します。
  • 免除待ちで支払えない：「免除証明の確認待ち」のあいだは金額が決まりません。証明を見て「免除を認める」か「免除を却下」します。
  • 修了できない：本人確認済みか、対象科目の視聴が足りているか、開催の長さが2時間・1時間30分・1時間30分か、カメラOFFで出席を外していないかを見ます。全免除は修了証を出しません。
