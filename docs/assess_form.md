# 初回アセスメント（保護者 → 職員の確認 → アセスメント）

Google フォーム「アセスメントシート（児童）」と同じ項目を、ポータルだけで取る。写真のアップロードはない（受給者証フォームと同じ。原本は持参。番号や負担額は受給者証の入力で別に聞く。リンクを持っているときだけ任意）。

## 流れ
1. 職員：ポータル **レオ → アセスメント** で児童名を入れて「リンクをコピー」。まだ利用者情報にいない児童でも、名前だけで作れる（30日有効）。
2. 職員：リンクを公式LINEの1対1トークに**手で**貼って送る（自動では送らない）。
3. 保護者：`assess.html?t=…` を開き、わかるところだけ入力 → 同意 →「入力内容を確認する」→「この内容で送る」。
4. 職員：届いた入力を開き、いまのアセスメントと見くらべる。違うところに色がつき、チェックが入る。値は直せる。
5. 「確認して反映」で、チェックした項目だけ `leo_child_assess` に足す（ほかの項目は消えない）。「反映しない」で記録だけ残して終わる。

反映のボタンを押すまで、アセスメントは変わらない。受給者証・連絡先の台帳には書かない。直接入力・修正は、いままでどおり **利用者情報の「アセスメント」タブ**。

「いまのアセスメントを入れておく」で作ったリンクは、開いた人にその子のアセスメントが見える。その家庭の1対1のLINEにだけ送る。

## 連先生・Reo が実行する SQL
Supabase の SQL Editor で、次を**この順**で実行する（すでに入っているものは飛ばしてよい。どちらも再実行できる）。

1. `supabase/leo_assess.sql` … 表 `leo_child_assess`（本番に既にある想定。未実行の環境だけ）
2. `supabase/leo_assess_form.sql` … **今回追加**。表 `leo_af_links` `leo_af_subs` と関数 `leo_af_*`

既存の表には列を足さない。`leo_child_assess` の中身も、保護者の送信だけでは変わらない（「確認して反映」のときだけ、送られたキーを足す）。写真の保管場所は作らない。

SQL を実行する前に画面だけ出すと、アセスメントの一覧は「SQL を実行したか確認してください」と出る。利用者情報のアセスメントタブ（直接入力）は、これまでどおり `leo_child_assess` だけで動く。

## 項目
見出しはフォームと同じ（`assess_lib.js`。確認用の一覧は `tools/assess_tab_spec.json`）。保存先は `leo_child_assess.data` のキー。以前のキーはそのまま（例：`birth` `allergy` `wish_life`）。フォームにあってポータルになかったものだけ足した：`name_kana`（児童名（ふりがな））、`guardian`、`address`、`phone`、`guardian_phone`、`emergency`。

保護者の送信で必ず必要なのは、児童名（ふりがな）と、個人情報の取り扱いへの同意だけ。アレルギーは「有り／無し」、健康状態の「〜か」は「はい／いいえ」。保険証・受給者証の欄は空で送れる。入れるなら `https://` のリンクだけ（保護者）。職員が反映するときは「原本は持参」のようなメモも残せる。

行の名前（児童名）は、リンクを作ったときの名前。保護者が書いた児童名が明らかに違うときは、確認の画面で止まる。

## 個人情報の扱い
- 診断名・服薬・家族を含む。見るのはレオの職員。リンクの発行・届いた入力の確認・反映は `can_manage()`（児発管・事務・管理者）。
- 保護者の画面から読めるのは、リンクの児童名と「送信ずみか」だけ。前回の内容を入れたリンクはその子のアセスメント項目だけ（ほかの児童・備考の列は返さない）。
- 表 `leo_af_*` は `can_manage()` だけが読める。書き込みは関数だけ。1時間に5回までの送信制限。
- 反映後の本文は、これまでどおり `leo_child_assess`（レオの職員が読める／編集は `can_manage()`）。

## 見本
- 保護者：`assess.html?demo=1`（前回の内容ありは `?demo=1&prefill=1`）。送信しない。
- 職員：`index.html?demo=1#leo/assess`。リンクは見本の URL を出すだけで、保存しない。

## テスト（架空データのみ）
- `node tools/assess_form_check.js` … 項目がフォーム仕様と一致するか、検証、タイルが Google フォームでないか
